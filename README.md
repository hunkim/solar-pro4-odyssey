# Solar-Pro4 Odyssey — Book I 한국어 번역

## 프로젝트 개요

호메로스 《오디세이아》 제1권(1-141행) 고대 그리스어 원문을 **Solar-Pro4 모델로 한국어로 번역**한 프로젝트입니다.

- **원문 출처**: Perseus Digital Library (퍼블릭 도메인, License Free)
- **번역 모델**: Solar-Pro4 (Upstage AI)
- **번역 스타일**: A형(서사시 문어체) + D형(현대 독자용) 2종 제공
- **번역 대상**: Book I, 1–141행 전체

## 번역체 선택

뷰어 앱에서 두 가지 번역체를 toggle로 선택할 수 있습니다.

### A형 · 서사시 문어체
- 고전적 어조(~도다, ~소서, ~노라)
- 서사시다운 장중하고 격조 있는 표현
- 호메로스적 화자 거리감 유지
- 신화적 호칭·신명 존중

### D형 · 현대 독자용
- 읽기 쉬운 현대적 호흡
- 약간의 의역과 적응으로 이해도 높임
- 일상적 어휘와 문장 구조
- 서사시 골격은 유지

## 파일 구성

```
/
├── index.html        # 뷰어 앱 (단일 HTML, 반응형, 모바일 우선)
├── translations/
│   ├── book1_A.md    # Book I 전체 A형 정제 번역문
│   └── book1_D.md    # Book I 전체 D형 정제 번역문

```

## 사용 방법

1. `index.html`을 브라우저에서 열거나 Vercel에 배포
2. 상단 toggle에서 A형/D형 선택
3. 스크롤 또는 터치로 읽기
4. 모바일에서는 터치 스와이프로 번역체 전환 가능
5. 좌우 화살표 키로 번역체 전환 가능 (데스크톱)

## 번역체별 예시 (첫 구절)

### A형

> 무사 여신이여, 내게 일러 주소서, 그토록 온갖 겪음 많던 사내가
> 트로이아의 거룩한 성채를 헐고 난 뒤 얼마나 많이 떠돌았는지,
> 수많은 사람들의 성읍을 보았고 그 마음씨까지 알아버렸으며,
> 얼마나 큰 고난을 바다 위에서 겪었는지—그 가슴속 억울함을 풀며
> 제 목숨과 전우들의 귀향을 찾고자 했건만,
> 그러나 그는 전우들을 구원하지 못하였나니,
> 저희 자신의 허물 탓으로 다 망해 버렸으므로.

### D형

> 노래하라, 여신이여. 나에게 말하라. 수없이 길을 헤매며 고난을 겪은 사내에 관해,
> 트로이아의 신성한 성채를 무너뜨린 뒤 수많은 사람들의 도시를 보고 그들의 마음을 알았으며,
> 바다 위에서 숱한 고통을 겪은 그 사내에 관해 —
> 그의 마음에 맞서 싸우며 자신과 동료들의 귀환을 구했으나,
> 동료들이 자신들의 무모한 짓으로 멸망했기에 그조차도 동료들을 구하지 못했음을.
